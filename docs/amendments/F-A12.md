# F-A12

Out-of-page signal on the transition to a `bad` state while `document.hidden`:

- `document.title` prefix `(N) `;
- `navigator.setAppBadge(N)` where supported;
- service-worker `showNotification` with `tag: sid`, where `notificationclick` focuses or opens the page and calls `focusOpen(sid)`.

Notification permission is requested from a user gesture (first card creation, or the chip menu).
Desktop only for v1.
