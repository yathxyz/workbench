# F-A22

The view is per device, like the camera (F-A7): the entered workspace, the focus tabs and the perspective live in `localStorage` (`wb-view-<host>`, try/catch), never in the board.
Inside a perspective, a save writes the manual layout (each node's manual folder, rectangle and order, the stashed folders, no derived folders or ghosts), so the board file always holds the manual perspective; a card shown in a focus tab is saved at its place on the canvas, not at the size of the screen.
A clean tab inside a perspective that takes another tab's board goes back to manual, takes it, and builds its perspective again.
A board saved inside a perspective before this amendment is turned back into its manual layout when it is loaded or taken, and lends its view to a device that has none yet
