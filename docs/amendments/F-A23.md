# F-A23

Keys are bindings in the keymaps of `web/keys.ts` and nothing else (§6.4).
A card that has the keyboard keeps the keys it needs: a shell gets every key but ``Ctrl-` `` (so C-k, C-j, Alt-B, Alt-digits and Alt-arrows reach the program and do nothing on the board), a page leaves only the palette, dock, tree, dictation and view keys.
Leader Esc leaves any card with the card still selected, and the leader pressed twice reaches the card (NUL for Ctrl-Space in a shell).
An artifact forwards the leader to the board through the bridge (`{t:'key', key:'leader'}`, the leader named in `hello.keys` and in a `{t:'keys'}` message when the user picks another).
The palette's C-j/C-k move its selection
