# F-A25

Block cards (hypernotes H0, `docs/HYPERNOTES.md`): a ```` ```html {#id} ```` fence in a page can be torn out as an `artifact` node with `block: {page, id}` and a `ref` edge from the page.
The node keeps no source or versions; it renders the block in an opaque-origin `srcdoc` frame (no `allow-same-origin`) in both modes, with `sample` and `db` declared, and reloads 400 ms after an edit changes the block.
A block without an id gets one in its info string.
A missing block or page shows a notice in the card.
