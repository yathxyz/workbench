# F-A27

**Edwin frames** (edwind spec §9, R8.16-R8.20, R13.7).
`app.js` reads `/api/info.edit` once at boot: `false` kept the CodeMirror page path until F-A39 retired it; `true` loads the Edwin runtime as `/edwin/manifest.json` lists it (edwin-web's, `api` 1: the scripts in order, then the shipped Scheme sources; another `api` fails the boot), and calls `Ed.bootServed` over one `/edit` WebSocket per tab (`device` = `localStorage` `wb-device`, `cid` per tab in `sessionStorage`).
A page node then carries `buf` (its file under `notesDir`) and no `text`: a card is an Edwin frame on the shared buffer, made lazily (within the viewport plus one viewport of margin at zoom ≥ 0.45, or focused; at most 24 per tab, least recently drawn unfocused first); otherwise the card shows the 12-line snapshot from the replica text (or the node's cached `snap`); a replica off screen for 5 min is closed.
Pages without `buf` are migrated on load through the replica to `notes/<slug>.md` (`-2`, `-3` on a collision with other text; a file with the same text is linked; edwind's `notes-fill` writes the text only into an empty file, in one step, so two tabs migrating at once write it once), their anchors re-created as shared markers, one console line per page.
The board is saved at once, and a migrated page has no frame and takes no edit through the replica until that PUT's 204: a migration whose board save never lands (tab closed, PUT failing or paused, a 412 on the conflict bar, where edwind spec R8.17 would restart the migration) leaves the file with the node's text, so the next load links it again.
Edits made meanwhile wait for the save, 10 s at most.
Enter focuses the frame, Shift-Enter opens the focus tab, Edwin owns every key but the board leader, leader then Esc returns to the board.
Anchors are `meta.anchors` (ink strokes use `ink-<stroke id>`), drawn as chips and ink lines from `frame.lineTop`.
`read_node` and `write_page` go through the replica.
Sessions `ed-*` are never offered as orphans.
The Editor view is a second frame on the same buffer (no CodeMirror mirror).
`/edwin/` serves the console (`edwin/console/index.html`); `sw.js` caches the runtime with the shell (`workbench-shell-v4`; since v8 what the manifest lists).
`window.__canvas.pageText(id)` is the page text in either mode; `window.__perf.frame` the frame creation timing and live count.
Block cards (F-A25) work on frames as on CodeMirror: the fence line carries the tear-out button as a chip, the palette command and `tear_out_block` read the page through the replica, a card's page keeps its replica open while the card is live, and an edit to the replica from any origin (this tab, a tool, another tab) reloads the cards.
A page's `snap` is written by the tab that made the edit (by every tab for a disk, server or agent edit), and a tab whose only change is a `snap` takes another tab's board instead of showing the conflict bar
