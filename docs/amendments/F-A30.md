# F-A30

**Tasks board fits its cards.**
The four columns share the tasks view's width (`minmax(0, 1fr)` each) and stay that width whatever a card holds: every grid inside a column has a `minmax(0, 1fr)` track, so a long unbroken source path or title no longer stretches a card past its column.
Titles and meta wrap anywhere.
The source path stays on one line and loses its middle: the head ellipsizes and the last 14 characters (file end and line) stay; hovering shows the full path, then the task's address (the address also sits in `data-addr`).
The view, not the window, picks the column count (a container query: 4, then 2 at 960 px, then 1 at 560 px), so the dock narrows it too.
Columns do not size to their content: one long path would then set the layout and push Done off the screen.
