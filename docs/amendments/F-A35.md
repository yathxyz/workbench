# F-A35

**Stable card ids.**
A card without a block anchor is `path#N` (its head line), so its reviews orphan when lines above it change.
edwind's `notes-reviews-append` mints a block anchor (` ^xxxxx`, five base-36 characters, retried on a collision with the file's anchors) on the head line of such a card the first time it is reviewed, as an edit attributed like any notes write, and logs the review under `path#^xxxxx`.
The card's earlier reviews under the line id (any host's log, `#fwd`/`#rev`/`#cN` siblings included) are copied into this host's log under the new id with `from` naming the old one, once; the old lines stay and match no card.
A later review sent under the line id (a page that has not reloaded) is logged under the anchored id.
The answer adds `anchored: {old: new}` when it did either.
An org heading keeps its tags before the anchor.
