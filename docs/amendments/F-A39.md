# F-A39

**CodeMirror retired** (Edwin E4, edwind spec R9.21).
Edwin frames are the only text editor: the vendor bundle carries xterm, its fit addon, perfect-freehand and rough.js, and no CodeMirror package is in `tools/package.json`.
Where edwind runs (`editSocket` set) every page is a frame, as F-A27 says, with no flag: wb-web has no `frames` key.
The page also makes local frames for the ACP prompt editor and the Agents transcript reader (F-A48), not backed by edwind files.
Where edwind does not run (the demo, no `edit.socket`) there is no page editor and pages are **read-only**: a card shows the text in a `pre.ro-text` with a notice ("Read-only in the demo: …" in the demo, "Page editing needs edwind" when served without it), the Editor view the same; a page with `buf` shows its `snap`.
Reason: with no edwind there is no text authority for the page file, and a second editor kept only for this case is the code E4 removes.
The board's own edits (ink notes, Add page text, `write_page`, block cards, anchors from ink strokes and refs) still change a read-only page through one page API (`pageState`, `pageText`, `pageEdit`, `pageEdits`, `pageSetText`, `pageAnchors`, `pagePoint`, `pagePosAt`) that goes to the replica on frames and to `n.text` otherwise, mapping anchors as edwind's after-markers.
`write_page` on a `buf` page with no replica fails with "page editing needs edwind".
Dropped with CodeMirror: the CodeMirror outliner keys (Enter continues a list item, Tab and Shift-Tab indent; Edwin's markdown-mode has its own), the `[[`-completion and block-ref widgets of the CodeMirror path, the vim toggle (`S.vim`; Edwin has evil), and the `page` key interior.
Edwin's `[[` completion offers the board's card and folder names too (hook `linkNames`).
The buffer address under the cursor (`showBufAddr`) works on frames.
Opening a page that has not moved to edwind yet in the Editor view moves it first

**Pages (F-A27, F-A39):** the served sections of `tests/ui.mts` always run with edwind, so every page is an Edwin frame (the harness's `--frames` and `WB_FRAMES` are gone with CodeMirror); the demo section runs the read-only pages.
Checks read a page's text through `window.__canvas.pageText(id)` and change it through `pageEdit`/`pageSetText`, which work in both.
