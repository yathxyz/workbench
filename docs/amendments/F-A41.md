# F-A41

**Media cards.**
An `op` node is `{kind:"op", name, op, prompt, provider?, model?, size?, n?, out?}`, `op` one of `imagine`, `edit`, `describe`, `expand`.
Its inputs are the cards with a pipe edge into it: a page or a quote gives its text, an image card its picture, another op card its picked image (else its text).
`imagine` and `edit` go to `POST /api/media` with the card's provider and model (one of `/api/info`'s `media`), size (1024×1024, 1536×1024, 1024×1536, 512×512) and 1–4 variations, the input texts before the card's prompt; `edit` sends the first input image (it must be in the blob store).
`describe` (needs an image) and `expand` (an idea grown into a detailed image prompt) go to `sample`, the model the assistant uses, so no step is tied to one vendor.
A run stores `out:{sig, at, images?:[{blob, mime}], pick?, text?, err?}`; `sig` hashes the op, its settings, the prompt and each input (blob hash or text hash), and a card whose current signature differs is **stale**: amber ring, "Run again", a badge.
Variations show as thumbnails; a click picks one (the cards it pipes into take it, and go stale), a double click or → takes the pick out as an image card on the same blob (or the text as a page) with a spawn edge.
✦ on an image or op card makes a new media card fed by it (edit when a provider exists, else describe).
The palette has "New media card: imagine/edit/describe/expand" and "Run the stale media cards", which runs every stale or never-run card and everything downstream of one, upstream first.
A failed run keeps the reason on the card.
Without a provider (demo mode, or no `media` in `web.json`) imagine and edit say so and send nothing.
Ctrl-Enter in the prompt runs the card.
