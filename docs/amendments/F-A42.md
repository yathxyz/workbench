# F-A42

**Copy as PNG / Copy as SVG.**
A sketch card's header has PNG and SVG; the selection chip has them while strokes are selected, and the palette has "Ink: copy as PNG/SVG".
The ink (the selected strokes, else the card's own, never ink anchored to a page's lines) is drawn as the board draws it, each stroke's perfect-freehand outline filled with the light theme's ink colour (`#000000`, `#a60000`, `#0031a9`), on a transparent ground, cut to the ink with a 16-unit margin.
PNG: twice the board's scale (at most 8192 px a side), written as `image/png`.
SVG: one `<path fill>` per stroke in a `viewBox` of the ink box, written as `image/svg+xml` where the browser writes that type (`ClipboardItem.supports`), else as text.
For Krita, Inkscape and other programs (the Krita round trip's first step).
