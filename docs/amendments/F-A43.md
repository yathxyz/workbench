# F-A43

**Server-only paths leave the frontend.**
wb-web answers 404 to `/api/hosts` and `/api/tmux*` and 403 to unit start, stop and restart (§3.7, W-8, W-14), and the hosts it serves run no Emacs.
So the frontend has no tmux perspective, `tmux:` address, adopt or session ghosts, `list_tmux`, `adopt_tmux` or `shell_detach`; no Unit start/stop/restart commands or `unit_control` (`unit_status` and `host_status` stay: they only read); no add-host button, host commands, `list_hosts` or `host_folder`; and no Emacs card, `open_in_emacs` or "New Emacs buffer…".
`shell_send`, `shell_interrupt`, `shell_logs` and `shell_kill` take a board path or the active shell.
A note or file that edwind does not open as a page (edwind down, read-only, not UTF-8 text) opens nothing and a toast says why.
The host resolvers (`hostOf`, `hFetch`) stay until a refactor folds them into the one serving daemon.
