# F-A44

**No hosted mode.**
The single-file build for claude.ai (M5-N's `dist/canvas-workbench.html`, `tools/build-artifact.py`) was never made, and `/api/info.dist` is always `null`.
So the frontend has no `CANVAS_HOSTED` flag (it hid the export download, refused the `downloads` capability and changed two notices) and no "Artifact: open the Workbench demo inside itself" command.
The ui suite's demo page is the same inlined page opened from `file://`, without the flag.
Artifact cards keep their own bridge (`window.wb.use`, F-A46).
