# F-A46

**The artifact card is agent-neutral** (2026-11-16).
A page in an artifact card reaches the Workbench through `window.wb.use(name)` (was `window.claude.use`; no alias), and its handshake message is `{wb:'hello'}` (the host never sent the `ping` the bridge answered, so that listener is gone).
The board page itself no longer asks a `window.claude` for `sample` (a leftover of the hosted mode of F-A44): `sample` is the server's or nothing.
The UI says "HTML card" and "language model", not "Claude artifact".
The New dock has no Page button: a page is made by double-click on the canvas, "New page" (palette, context menu), `n` in the navigator, "+ Page" in the Editor view, Today and links.
