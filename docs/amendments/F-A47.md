# F-A47

**The mesh in the page** (2026-11-17; Agents interaction extended by F-A48).
With `api` in `web.json` (`/api/info.mesh`), the page keeps `OBS`, the observed sessions of §3.8.3 as `/rpc` carries them (§3.5.3), and draws one overview from them and from `SESS`.
**Rows.**
A row is an observed session, with its descendants under it, or an agent session of the hub that no harness reports.
An observed session is joined with the hub session named by its `wbSession` only when the observed record has no `parent` and that session is on the same host (a host can name any `wbSession`; it is believed for its own sessions only), and then has that session's card.
A subagent MUST NOT join a hub session, even if its parent is absent from `OBS` and it repeats the enclosing `wbSession`.
A joined row is waiting when either side says so: the hub's ACP state when it is `waiting_permission`, `waiting_input` or `error`, else the observed state.
A row is live until its record has ended; a record that ended (it went silent, say) while the hub still runs the agent session it is joined with stays live, in the hub's state.
**Agents overview.**
The main Agents view groups root rows by repository (`repo`, else `project`), the groups and the rows ordered by waiting for you, working, the rest, ended, and then by start time, newest first, so the list does not reorder while sessions work; a row shows title, harness, model, host, what it is doing (the pending tool and input, the running tool, or the state) and the age of its last event.
A record with a shown, live `parent` lists under that session, indented to any depth, even across repositories; otherwise it is a root in its own repository group.
Cycles never hide rows or recurse forever.
The second line adds worktree and branch, omitting nulls and displaying a worktree equal to its branch once; full values remain in title attributes.
A descendant in another repository names its repository there.
Ended sessions list when Ended is ticked.
Parents can collapse; a collapsed row shows the count of all shown descendants and their worst state, including waiting descendants at any depth.
Collapse state lasts for this page only.
A click selects its separate detail pane, with folder, model, mode, last prompt and reply, counts and the last 12 lines of the tail, plus repository, worktree, branch and a known "started by" link selecting its parent, and "Show on canvas" for a row with a card, "Add its card" for a hub session without one, and "Copy id".
Rows and the selected live backend keep their DOM identity across activity and metadata updates; structural changes reuse surviving keyed rows.
**Status and attention.**
The status line has `mesh N · M waiting` (all live rows, including collapsed descendants; a click opens Agents at the first waiting row and expands its ancestors).
An observed session that waits is an Attention item `obs:<id>`, unless it is joined to an agent card whose own session waits, which is listed already; joined to any other card, the item is that card's (it counts as a card that needs a look, F-A15); else Enter opens Agents at the row.
An Attention list that is open follows these items.
The out-of-page signal (F-A12) fires for such a session, with the same exception, as for an agent card, and its notification opens Agents at the row in a page that is open.
Joined to an agent card it fires under the card's sid, so the hub saying the same after the harness is one signal; joined to an agent session of the hub that has no card, the hub saying that it waits fires it under the observed id.
**Graph.**
With "Agents on the mesh" ticked (the default), each live row is a `session` node (`mesh:<id>`, a diamond in its state's colour).
A session is tied to a `host:<name>` node (a hexagon), to a `proj:<repo-or-project>` node (a hollow square; one node for a repository display name across hosts) and to its card when the card is in the graph; a child is tied to its parent alone, by a `spawn` edge, or stands as a session when that one has ended.
A session's card in the graph shows what it is doing and the end of its tail, kept current in place, with "Show in Agents" (also double-click).
A session that starts or ends moves the layout; a change of state or title only redraws.
A node that goes while the pointer holds it ends the drag and is not selected; the open card is drawn again when the layout moves, and a button that still names a node that went selects nothing.
Identical repository display names on different hosts share one node; legacy project names still share one fallback node.
