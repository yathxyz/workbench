# F-A50

**Session permission policy, without a page change** (2026-11-17; hardened 2026-11-18).
Optional validated ordered rules live in the hub, installed by `SpawnAcp.policy` (API create and `/acp` spawning open), replaced by epoch-checked `acp.set_policy` / control `POST /v1/sessions/{sid}/policy`, and readable as `Summary.acp.policy`.
No default policy; empty rules remove it.
First match wins, including ask; malformed evidence or absent once-only options ask.
Execute permits empty locations and uses `rawInput.command`; other kinds require locations and cannot match rules with `programs`/`command`.
Only `command`, optional plain `cwd` and inert `timeout`, `async`, `pty`, `description`, `run_in_background` input members are accepted.
Cwd is resolved against session cwd and root-checked; leading `~`/`@`, any `:`, and non-ASCII/control characters ask, as do dequoted `cd` operands starting `@` or containing any `:` or non-ASCII.
Only the persisted configured agent key `omp` is known to reset cwd per command; **every other agent's execute requests always remain pending**, since a manually approved directory change would invalidate all later cwd assumptions.
Other kinds are unaffected.
The bounded shell subset, lexical roots, exact command-name/path `programs`, assignment provenance, builtin/glob/dispatcher refusals and their limits are specified in §3.4.5.
An assignment-shaped word after a leading redirection asks.
Canonical regex input dequotes words and places each simple command's words before its redirections.
Allow requires positive patterns on both raw/canonical texts and no negative on either; reject/ask require positives on either and exclude negatives only on both.
Limits: **256 KiB serialized policy**, **64 KiB compiled per pattern**, **4096 bytes per root**, **8 KiB raw regex input**, **100 ms decision deadline checked before each pattern search**; reaching a pattern rule beyond its input/deadline limit makes the whole decision ask, never fall through.
Oversized regex errors explain that Unicode classes are large and recommend ASCII classes or scoped `(?-u:…)`.
Earlier pattern-free decisions stand.
Invalid journal policy replacements **clear policy until a later valid event**.
Policy answers only during active uncancelled prompt turns; outside-turn and post-cancel requests take the manual pending path.
Existing pending requests remain pending across replacements.
`permission_auto` atomically journals request, outcome and zero-based rule/action without pending exposure; `policy` journals replacements.
Elicitations are never automatic, and incarnation/epoch checks prevent inheritance or stale changes.
This is cooperative text matching, **not a sandbox**: symlinks, program argument semantics, scripts and adapter rewrites remain outside the guarantee.
omp retains one shell: manually approved function/alias/option changes can affect later automatically allowed commands, although policy never approves their definitions.
Subcommand exclusions are best-effort; withhold credentials for forbidden operations.
No `web/` change.
