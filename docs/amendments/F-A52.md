# F-A52

**Managed git worktrees for local ACP sessions** (2026-11-19).
`POST /v1/sessions` accepts `worktree:{branch, base?}` only on a local spawn when the connected hub advertises `acpWorktree:true` (§3.2.3, §3.8.2).
The hub creates `<main-root>-wt/<branch-with-slashes-replaced-by-hyphens>` from a non-bare main or linked checkout, including when `cwd` is a subdirectory (§3.2.7).
If git reports a separate metadata directory from a linked checkout and cannot identify the main root, the hub refuses rather than choosing the wrong sibling.
It refuses an occupied path or a branch already checked out elsewhere, uses an existing local branch as is, and otherwise creates a branch without upstream from the resolved base commit (default: this checkout's HEAD).
Both names are checked before git runs; the client supplies no destination path.
The new root becomes the session's `cwd`, and `acp.managedWorktree:{path, branch, mainRoot}` records ownership across restart and revive, separately from the web's inferred `worktree` string.
If session creation is refused after checkout, the hub rolls the clean worktree back without force, leaves the branch, and reports the remaining path if removal fails.
`DELETE /v1/sessions/{sid}/worktree` requires control scope and removes only that session's recorded worktree while the agent is stopped; 409 means running or removal refused, and 404 means no record.
Git's non-forced removal protects changes and non-ignored untracked files, not ignored build products.
Removal leaves the branch and clears the record on success; killing or forgetting never removes a worktree, so forgetting leaves the checkout on disk.
The optional `git` executable in `hub.json` enables this capability; `services.workbench.gitPackage` defaults to `pkgs.git` (§3.7.2).
Git runs with bounded output and deadlines, without a shell, interactive prompts or hooks, but uses the repository's and user's own configuration, including checkout filters.
This sets a working directory; it does not confine the agent to it.
There is no remote worktree creation, force removal, fetch, branch deletion, PTY or page change.
