# N50

Enter on the active shell card puts the keyboard in its terminal on the canvas; Shift-Enter opens the card as a focus tab.
Opening the source PDF as a focus tab during a quote jump locates the quote with both cold and cached text, even when the old page layout would clamp the scroll.
If opening focus or resizing replaces a quote jump's text layer, the jump scrolls and highlights on the latest layer without waiting for discarded renders.
A quote without highlight spans preserves the user's scroll unless layout clamped the jump short of its target page.
Scrolling away from a clamp and back to the top while the layer renders preserves the user's chosen position, even when Down and Up produce a single scroll event.
Following a reference to a PDF whose pending load fails still focuses the mounted reader.
Closing the source PDF or switching PDFs settles a pending quote promptly even if the text layer has stalled.
Manual find with no highlight spans preserves a scroll made while the text layer was rendering.
Manual find waits for the replacement text layer after a resize before reporting success.
A quote jump on the same pending layer lands on the quote, not on an earlier manual find, even when a resize replaces the layer before the original stream is released.
Opening a different card does not give the interrupted jump the keyboard.
Leaving for another card, fitting the board, or leaving a top-level workspace during asynchronous quote lookup cancels the jump before it can scroll or take the keyboard.
A focus tab opened during Back returns to that flight's destination.
Browser Back to a board card, folder or root leaves focus before fitting the canvas.
The address remains at the Back destination when the address bar is synchronized with the canvas.
Queued fragment changes from the board root to a card and back select the card before returning to the root, even without popstate.
Root navigation releases the deselected card's keyboard and clears all its tree highlights.
Palette jumps to a saved view or coordinates and keyboard camera Back and Forward leave focus and use the canvas camera for zoom and history.
