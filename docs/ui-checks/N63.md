# N63

Images and the clipboard (F-A32).
`C-v` on the board resolves to `clip.paste` and the keydown is not prevented.
A 40 × 30 PNG pasted into a focused text field makes no card.
Pasted on the board it is a picked image card with a 64-hex `blob`, `mime` `image/png`, `iw`/`ih` 40/30, no `src`, its `<img>` loaded from `/blob/<hash>`, which answers 200 `image/png` with an immutable cache; the board file holds the hash and no `data:image`.
An SVG file pastes as a 20 × 10 PNG; `POST /api/blob` with SVG bytes labelled `image/png` is 415; a PNG dropped on the canvas is a card.
A `copy` with the card picked is taken and carries the items and the `/blob/` URL; pasting that makes a second card on the same `blob`, and so does a paste holding a different 7 × 7 PNG with the copied text.
`n62 label` pastes as a text shape, an https URL as a web card, `# n62 notes` with lines as a page named `n62 notes` holding them; `cut` with the label picked removes it and carries its text.
Two cards joined by an arrow, picked with a rect shape that sits in a folder, are copied and pasted: the copy holds the arrow, the pasted arrow is bound to the two new cards and the pasted rect is in no folder.
