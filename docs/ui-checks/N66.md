# N66

(demo) Right-click fixes (F-A34).
In a shell card, after a right-click the keys are back in its terminal when the menu is closed by Esc, by a press outside it, or by Copy.
With a canvas shell card selected and the keys in the docked terminal, the menu key opens the Terminal menu for the dock (Copy sees the dock's selection), anchored on it.
After a Shift-F10 the page did not get, a right-click on the canvas opens Canvas at the pointer.
A right-click on selected ink opens Selection.
A right-click on the status line is not prevented and opens nothing.
In the graph view, `.` with no node selected opens no palette
