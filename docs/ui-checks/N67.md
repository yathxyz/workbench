# N67

A save between a page's `GET /api/board` and its `/rpc` subscription (the boot GET answered with the board from before another writer's PUT): the clean page takes the newer board and its tag from the connect snapshot's `board{etag}`, with no bar.
A boot link to a board card missing from the first snapshot opens it on adoption; a cold note link opens its navigator entry once the index arrives.
Neither restore overrides a newer navigation.
The restore expires after five seconds, a rejected note index, or the first board adoption for a missing board target, and the URL resumes tracking navigation.
Switching desks, selecting another navigator row by click or key, or opening another editor file supersedes the boot link even within the same view.
