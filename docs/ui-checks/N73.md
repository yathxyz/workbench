# N73

PDFs (F-A40).
A two-page PDF written by the suite (Helvetica text, a link on page 1 to page 2): `/api/raw` serves it whole (200, `application/pdf`, attachment, sandbox CSP) and `bytes=0-4` as 206 `%PDF-` with `Content-Range`; a text file is 400, a range past the end 416; `POST /api/blob` takes the bytes as `application/pdf` and `/blob/` serves them as an attachment.
Opened from its host path: 2 pages, page 1 drawn with a text layer and a link box, badge `p. 1 / 2`; `pdfText` has both page markers and texts; `read_pdf` from 2 to 2 has only page 2; `read_node` reads from the reading page (page 2 by then); `open_pdf` makes a second card on the path.
Selecting "quote target" in the text layer: `pdfSel` and `selectionOf` give it, ❝ makes a ref card with page 1, prefix ending "The ", suffix starting " sits", label `<name> › p. 1` and a ref edge; finding it asked on page 2 finds it on page 1 and lights a span; an absent text is not found.
A click on the link makes a peek image card (`at.page` 2, a blob hash, a ref edge, ⤴).
`pdfGo` to page 2 saves `pos.page` 2, badge `p. 2 / 2`.
With the scroller focused the interior is `pdf`, `j` is `pdf.down`, `q` `pdf.quote`; `g` goes to page 1, `G` to page 2.
A dropped PDF is a pdf card on a blob hash that opens with 2 pages.
A removed card has let go of its document.
If the second card is removed while its first page is pending, the load settles without a document or an error when that request rejects.
