# N75

Copy as PNG / SVG (F-A42).
A sketch card with a red and a black stroke: the SVG parses, has two paths filled `#a60000` and `#000000`, a width between 140 and 200 and a matching `viewBox`; the PNG is twice as wide, its corner transparent, over 200 inked pixels.
With one stroke selected only it is copied and the chip shows SVG; cleared, it hides.
The header has PNG and SVG; with clipboard permissions, Copy as SVG puts the SVG on the clipboard (as `image/svg+xml` or text) and Copy as PNG an `image/png`.
