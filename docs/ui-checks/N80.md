# N80

Task references in Agents (F-A51).
The row shows a long task ellipsised, and the Task detail line contains the entire value.
A whole HTTP or HTTPS issue URL in Details is a link to that URL in a new tab with `rel="noopener noreferrer"`.
A `javascript:` reference and text containing markup appear literally, without creating a link or interpreting HTML.
For a joined row, the hub task wins until it is cleared, when the observed task is shown instead.
From the default repository grouping, `g` groups root rows by task with a single last group for those without a task; `g` again restores repository grouping.
Two roots with the same task but different repositories show both repository names in task mode and neither in repository mode.
In task mode, descendants stay in their root's group and show their repository when it differs from their immediate parent's.
A literal task named `No task` has a separate heading from the final taskless group.
An empty repository heading stays empty when switching back to repository mode.
