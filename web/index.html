Workbench

    

    

      

        
Find and run

        

          
Ctrl-K
Fuzzy search over pages, shells, agents, folders, anchors, saved views and every command. Type letters in order: cwb finds canvas-workbench.

          
: · Ctrl-Shift-P · >
Commands only

          
Ctrl-N / Ctrl-P, Ctrl-J / Ctrl-K
Move in the palette

          
Alt-1 … Alt-7
Canvas, Navigator, Graph, Editor, Outline, Tasks, Review

          
Alt-B · Ctrl-` (or Ctrl-J)
Folder tree · docked terminal

          
Middle-drag · Alt-drag
Pan from anywhere, also over a terminal or editor; the middle button never pastes here. Space-drag pans too when nothing is being typed.

          
Boundaries
Items on one level never overlap: after a drop, a resize, an unfold or a new item, the others on that level move aside, folder tabs included, and the folder grows to fit. The palette's "keep a boundary" command turns it off.

          
Tab · Shift-Tab
Tab folds the active folder into a package (just its tab) and unfolds it again; Shift-Tab packages every other folder on the same level so one stays in focus, and a second Shift-Tab unfolds them all. Ctrl-Z undoes.

          
Enter · Shift-Enter · Esc
Enter the active folder as a workspace (everything else dims; the status bar shows where you are). On a card, Enter puts the cursor in it: the shell's prompt, the agent's composer, the page's text (a card off screen or zoomed far out comes into view first). Shift-Enter opens the active card as a full-screen focus tab. Esc steps out, or back to the canvas.

          
Ctrl-Space
Leader key, which-key style (press it twice to send Ctrl-Space itself to Emacs or tmux; the palette can move the leader to Ctrl-Alt-Space or F1): 1 to 9 switch top-level workspaces, ` last workspace, u up, f focus tab, q close tab, n/p next and previous tab, h j k l move focus between neighbours, H J K L swap with a neighbour, e/b/t/s folder modes free/pack/tile/stack, o optimise the board, O optimise this folder, c compact, F browser fullscreen, z fit all, # tag.

          
Shift-click a mode button · Ctrl-Space E B T S
Cascade: the folder mode (free, pack, tile, stack) is applied to every nested folder as well. Ctrl-Z undoes.

          
Note trees
note: in the navigator lists a note's headings as a tree (a heading's parent is the nearest heading above it with a smaller level; list items hang under their heading); h goes up to the parent heading. [[Title#Heading]], [[Title#^anchor]] and a bare ^anchor resolve as addresses (ga, wb go note:Title#Heading). The outline pane shows the heading tree of the focused page; click a heading to jump to it. A note's preview lists its backlinks.

          
Journal
journal: is year › month › day; journal:today is today's entry (created when missing: a board page in the demo, journal/YYYY-MM-DD.md under the notes in the local build). ]d / [d in the navigator go to the next / previous day that has an entry; the palette has Journal: today / next / previous. Journal perspective (Ctrl-Space v j): one folder per year with a folder per month, the day pages inside (index-only days as ghosts that open in Emacs; today as a ghost when it has no entry yet).

          
Links
link: lists every page and note with links, most linked-to first, with → out ← in counts; descend to see what a page links to (titles with no page are ghosts: Enter creates the page). Links perspective (Ctrl-Space v l, palette Perspective: links from a page…): the MOC view from one root: a folder per page, the pages it links to inside, nested where they link further; a page linked from several parents sits under the one that links to it most and shows as a copy under the others. Local build: links come from the daemon's index (/api/links, /api/backlinks, tool list_backlinks).

          
Tasks (Alt-6)
A task is a block whose first word is a keyword: TODO NEXT WAITING HOLD SOMEDAY DONE CANCELLED (Org's set; DOING/NOW/LATER still read). Right under it, Logseq-style: SCHEDULED: <2026-10-11 Sat>, DEADLINE: …, [#A] priority on the line, session:: and dispatched:: once dispatched. The view shows the board's pages and, in the local build, every task in the notes index, in four columns sorted by date. Keys: j/k pick, t/T cycle the keyword (written back to the file), Enter opens the line, d dispatches, r reloads. Dispatch pastes title and body into the first shell tagged #agent (on the given host) and records the session. wb tasks, wb task KW REF, wb dispatch REF [HOST] [SHELL].

          
/mcp
The daemon serves MCP (Streamable HTTP, JSON) at /mcp with the gateway's names: list_agent_sessions, inspect_agent_session, send_agent_session, interrupt_agent_session, list_work_items, inspect_work_item, create_work_item (writes a block into roam/inbox/tasks.md), dispatch_work_item, set_work_item, plus search_nodes, get_node, list_nodes, list_agenda, list_flashcards, create_note, create_flashcard, tag_node, host_status. Auth: Authorization: Bearer <token>.

          
proc: and unit:
The host's own trees in the navigator: ⚙ processes (from /proc: parent tree, command, cwd, unit; a board shell's process shows its card) and ⊙ units (systemd, failed first, each with its processes and systemctl status in the preview). Perspectives processes (Ctrl-Space v c: each shell card in a folder with the OS processes under it as ghosts, refreshed every 2 s inside the open workspace) and units (Ctrl-Space v u: one folder per host with a ghost per unit, tagged #active #failed #inactive; a unit that owns a board shell becomes its own folder). wb ps, wb units, wb unit restart|stop|start NAME [HOST] yes (the only mutating verbs; the palette asks first), wb health. The filesystem perspective marks hard links (⧉, a dashed edge to the other name) and mount points (⛁).

          
Status line
Bottom right: hosts up/all, ✗ failed units, ✦ agents running, ▦ cards due, ☐ open tasks, ! attention. Each count is a click to the matching place; ! attention (also wb ls attn:) lists what needs a look, one address per item.

          
tmux
Local build with canvasd --tmux-socket PATH: every shell card is a tmux session wb-<id> on that socket, so it survives a daemon restart (the card re-attaches). Sessions other programs made there (an agent's control-session, a plain tmux -S PATH new -s name) are listed under tmux: in the navigator (Enter adopts one as a card tagged #tmux; ⇠ or ✕ detaches it, the session keeps running) and in the tmux perspective (Ctrl-Space v x: one folder per session, sessions with no card as ghosts). From a shell: wb send tmux:@host/name 'text', wb logs, wb interrupt, wb kill, wb tmux, wb adopt name.

          
Ctrl-Space v, then m / p / f / t / x / c / u / j / l
Perspective: a folder is a view of one relation. manual shows the folders as you made them (the stored board); process derives one folder per shell that spawned others, nested as the spawn tree, with items outside the relation dimmed; filesystem (next version) groups by directory on each host. Switching back restores every manual folder and position exactly.

          
Host folders
New → Host (local build): a folder bound to another machine's daemon, shown as @name on its tab and #host in its tags. Shells and Emacs buffers opened inside run there; the navigator lists @name files; wb in those shells drives this board through that daemon. Hosts come from ~/.canvas-proto/hosts.json on the serving daemon, or type name=http://addr:port#token. A host that drops shows a red @name and ↻: shells inside the open workspace reconnect by themselves, others wait for ↻ or Enter. A running shell cannot be moved to another host.

          
Shift-C
Optimise the board: groups what is linked, spawned, piped or tagged together, lays each group out in flow order, packs the groups, snaps to the grid. Ctrl-Z undoes.

          
#
Tag the active node. Tags filter and describe nodes: #agent is a terminal running an agent (set by itself from the foreground process), #aggregator makes a node a container (a tagged terminal gets its own folder, and what it spawns lands there), #emacs marks Emacs buffers. Click a tag to filter; Esc clears.

          
wb
Agents in a terminal drive the board with the wb command (on PATH in every shell): wb tools, wb nodes, wb web URL, wb artifact-file page.html, wb card FRONT BACK, wb tag PATH agent.

Artifacts and review

        

          
Artifact node
A Claude artifact page in a sandboxed frame. It reaches the world only through claude.use(); you allow each capability once. ✎ edits the source as a page, "Artifact: publish from this page" ships it.

          
Node kinds
Shell (real PTY: run claude code, oh-my-pi or anything), Emacs buffer (emacsclient -t on a file), Web (a page in a frame; ↗ opens it outside when the site refuses frames), Artifact (sandboxed HTML page: published by Claude, or backed by a file any agent writes, reloaded on change), Sketch (write or draw with the pen; Aa turns the ink into a page), Page, Folder.

          
Review (Alt-7)
Space reveals, 1 to 4 grades, u undoes, s suspends, b buries, o opens the source, ? asks. Answer by thinking, typing, pen or voice.

Folders and canvas

        

          
Drag a header into a folder
The pointer decides where it belongs. Folders nest; moving one carries its contents.

          
◻ free · ▦ pack · ⊞ tile · ❐ stack
No gravity · rows in drop order · panes that fill the folder in dwm's golden-ratio spiral (the first pane takes 0.618 of the width, the next 0.618 of what is left the other way, and so on inwards) · a deck of cards. (The PaperWM ribbon is gone: it grew the folder past the screen.)

          
Workspaces: ⌂ · Enter · Esc
A folder becomes the desktop: ⌂ on its tab, Enter with it active, Ctrl-Space 1…9, or a double-click on its icon. The other top-level folders dim. The way out: the ⇱ Leave bar at the top, Esc, Ctrl-Space u, ⌂ on the tab again, or a click on any dimmed folder, which leaves and goes there.

          
⬚ Select an area (S or 6)
Drag a rectangle: every stroke, drawn shape and card fully inside it is selected (Shift-drag does the same from the select tool; Shift adds). Delete removes the lot; Ctrl-Z brings the ink and shapes back (a removed card is gone). The chip offers Sketch card, which turns the selected handwriting into a sketch card with an address, tags, arrows and Aa → text, and Aa → text directly.

          
Aspect ratio (⊞ again)
A folder tiles in the screen's ratio (its area kept), so Enter makes it the whole view: a workspace that is a desktop. ⊞ on a tiled folder (or wb mode F tile again, or the palette's "next tile aspect ratio") steps through 16:9, 3:2, 4:3, 1:1, 3:4, 9:16 and back to the screen's; the panes retile each time. Entering a screen-ratio folder that is smaller than the screen grows it to the screen's size at zoom 100%. A folder that is itself a pane of a tiled parent takes its size from the parent.

          
Tabs and headers
A folder's tab and a card's header keep their screen size at every zoom, but never run past their item: the name ellipsizes first, then the count, badge and tags go, then the mode buttons and all header buttons but ✕. Zoom in and they come back.

          
Resizing
Every card and folder has three handles: the corner (◢ on folders), the right edge (width) and the bottom edge (height). A tiled pane's edge changes its share of the split it sits in; the folder retiles live. A packed folder's size is what its items must fit: rows re-flow, and when they still do not fit the cards shrink together (down to a third); dragged below a deck's size the folder stacks, and a deck dragged open unstacks. Switching tile ↔ ribbon keeps the size the folder had before either, so nothing stretches.
